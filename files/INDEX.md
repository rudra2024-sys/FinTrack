🎓 KEY CONCEPTS
═════════════════════════════════════════════════════════════════════════════

CACHING LAYERS (3 places cache can hide):
  1. Browser cache (solved with: hard reload + disable cache)
  2. DevTools cache (solved with: disable cache checkbox)
  3. Node.js memory (solved with: fresh file reads in serve.mjs)

REQUIRED HEADERS (what we add to serve.mjs):
  1. Cache-Control: no-store
     → Tell browser: never cache this, always fetch fresh
  2. Pragma: no-cache
     → Legacy header for old browsers
  3. Expires: 0
     → Mark as already expired
  4. ETag: W/"timestamp"
     → Changes every request, forces browser to refetch

HARD RELOAD vs NORMAL RELOAD:
  Ctrl+R or F5        → May use browser cache (304 Not Modified)
  Ctrl+Shift+R        → Skips browser cache, always fetches fresh
  Cmd+Shift+R (Mac)   → Same as Ctrl+Shift+R

ONE SOURCE OF TRUTH:
  Before: Multiple index.html files (confusion/ambiguity)
  After:  Single explicit path (clarity/reliability)
